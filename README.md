## 📱 核心功能

### 1. 扫码验真（消费者端）
- 微信扫码验证产品真伪
- 显示查询次数（第1次/第N次）
- 动态防伪水印（防截图伪造）
- 正规合作机构查询

### 2. UDI 追溯（企业端）
- 扫码入库/出库
- 全链路追溯查询
- 效期预警管理
- 不良事件上报

### 3. 销售管理
- 分销商分级管理
- 销售目标追踪
- 数据报表看板
- 人员规划

## 🏃 本地开发

```bash
# 安装依赖
npm install

# 启动前端 + 真实 API 后端
npm run dev:full

# 或分别启动
npm run dev      # 前端
npm run api      # Express + SQLite API，默认 http://localhost:3001/api

# 如需旧 Mock 调试
npm run dev:mock

# 前端和 API 启动后，可做一次本地健康检查
npm run check:local
```

### 环境变量

可复制 `.env.example` 作为本地配置参考。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `VITE_API_BASE_URL` | `http://localhost:3001/api` | 前端请求的 API 地址 |
| `PORT` | `3001` | Express API 端口 |
| `DB_PATH` | `./data/sales-manager.db` | SQLite 数据库路径 |

### 本地连通性检查

如果浏览器提示 `127.0.0.1 拒绝建立连接`，先确认 `npm run dev:full` 正在运行，再执行：

```bash
npm run check:local
```

默认检查 `http://127.0.0.1:5173` 和 `http://127.0.0.1:3001/api`。如果前端或 API 使用了其他端口，可临时指定：

```bash
FRONTEND_URL=http://127.0.0.1:5175 API_BASE_URL=http://127.0.0.1:3001/api npm run check:local
```

## 🧬 胶原项目管理系统使用说明

这套模块用于管理医美机构的胶原针剂项目推进，适合记录从线索、启动会、发货、30天追踪到复购/样板沉淀的全过程。

### 页面入口

| 页面 | 路径 | 用途 |
|---|---|---|
| 胶原项目总看板 | `/collagen-projects` | 查看机构项目池、阶段分布、风险结构、导入/导出与新增机构 |
| 胶原跟进清单 | `/collagen-projects/follow-ups` | 集中查看所有机构的下一步动作，按风险和经营价值排序 |
| 胶原月度复盘 | `/collagen-projects/monthly-review` | 按负责人、阶段、风险、卡点项目、复购/样板机会做月度复盘 |
| 新增机构 | `/collagen-projects/new` | 手动新增一家机构项目 |
| 机构详情 | `/collagen-projects/:id` | 编辑单家机构状态、完成跟进、查看跟进历史、归档/恢复项目 |

### 推荐日常流程

1. 每天先打开「胶原跟进清单」，优先处理高风险、高价值机会。
2. 点「处理」进入机构详情页，完成本次跟进并填写新的下一步动作。
3. 机构不再推进时，在详情页点「归档项目」，默认不再进入推进中 KPI。
4. 每周在「胶原项目总看板」看阶段分布和风险结构。
5. 每月底打开「胶原月度复盘」，检查负责人表现、卡点项目和复购/样板机会池。
6. 点击「导出复盘」，生成 Excel 报告发给团队或老板。

### Excel 导入字段

在「数据导入」中选择「胶原项目」，可导入以下字段：

| 字段 | 说明 |
|---|---|
| 机构名称 | 必填，机构或客户名称 |
| 阶段 | 线索、待资料、待启动会、已签约、已发货、30天追踪、复购判断、样板沉淀、暂停 |
| 风险 | 低、中、高 |
| 负责人 | 项目负责人 |
| 城市 | 机构所在城市 |
| 来源 | 直营、渠道、经销商、转介绍等 |
| 决策 | 复购、续费陪跑、二次启动、样板沉淀、普通维护、暂停观察 |
| 评分 | 0-100，综合项目质量评分 |
| 发货日期 | 可选，格式建议为 YYYY-MM-DD |
| 30天状态 | 未开始、进行中、已复盘、暂停 |
| 医生培训 | 未排期、已排期、已完成 |
| 病例数 / 授权病例数 / 内容数 / GEO变化 | 用于30天追踪和复盘 |
| 下一步 | 当前最重要的跟进动作 |

### 导出报告

| 导出入口 | 文件内容 |
|---|---|
| 总看板「导出月报」 | 月度总览 + 机构项目池 |
| 月度复盘「导出复盘」 | 月度总览、负责人复盘、阶段结构、卡点项目、机会池 |

### 数据保存说明

当前胶原项目数据优先保存在本地 SQLite 数据库中：

- 默认数据库路径：`data/sales-manager.db`，首次启动会自动创建目录和种子数据。
- 前端默认连接 `http://localhost:3001/api`，看板标题下会显示「后端同步 / 同步中 / 本地缓存」状态。
- 如果后端暂不可用，前端会退回浏览器 `localStorage`，避免页面完全不可用。
- 「数据导入」里的胶原项目导入会批量替换后端项目池；「清空数据」会清空后端胶原项目。
- 重要数据仍建议定期用「导出月报」或「导出复盘」备份。

本地 SQLite 可用以下命令生成数据库快照，默认保存到 `backups/`，该目录不会提交到 GitHub：

```bash
npm run backup:db
```

如果使用了自定义数据库路径或备份目录：

```bash
DB_PATH=/path/to/sales-manager.db BACKUP_DIR=/path/to/backups npm run backup:db
```

### 回归验证

```bash
npm run test:collagen-api
npm run test:local-stack
npm run build
npm run check:deploy
```

`test:collagen-api` 会自动启动临时 API 和临时 SQLite，验证胶原项目的种子数据、新建、更新、跟进、归档、恢复、批量导入、重复 ID 校验和清空。

`test:local-stack` 会自动启动临时 API、临时 SQLite 和 Vite 前端，再调用 `check:local` 验证前端页面、API 健康检查和胶原项目接口，适合排查本地端口或服务未启动问题。

`check:deploy` 会在构建后检查 Vercel 配置、生产环境文件和 `dist/` 产物，避免 `/api/*` 被 SPA 兜底吞掉，或把占位 API 地址打进生产包。
